AGRA DRIVE SIMULATOR - PROTOTYPE
Open index.html in a modern browser with internet access (Three.js is loaded from a CDN).

Controls:
- Touch: LEFT / RIGHT / GAS / BRAKE
- Keyboard: WASD or arrow keys
- Manual gears: R, N, 1-6 buttons / number keys
- CAMERA: 3 camera views
- DAY/NIGHT, SPORT, DRIFT
- TUNING: colour, engine upgrades, turbo
- Open World / Taxi Mission modes

Note: This prototype uses an original performance-sedan shape inspired by the general proportions of sports sedans rather than an exact BMW M5 replica.
